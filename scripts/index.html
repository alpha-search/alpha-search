Welcome to AlphaSearch TerminalOBSIDIAN SLATE · LOCAL CACHE

A self-hosted, OpenBB-Workspace-style quantitative terminal. Every view is wired to the local FastAPI backend and cached through AlphaDB (60-second window) so the interface stays responsive — and never crashes — even when a data provider times out.

QUICKSTART
1. Type a ticker (e.g. NVDA) in the command bar to open its 7-tab Asset Signature Interface.
2. Open BUILD to drag a thematic cohort, then Run Quant Scan to populate the opportunity matrix.
3. CHRONOS charts price history (65/35), CONTRAST compares two filings (50/50), CURV draws the yield curve, FLOW streams news.
